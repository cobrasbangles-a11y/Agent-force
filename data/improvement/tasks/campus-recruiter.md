# Task

We're a mid-size fintech (about 900 employees) building our first formal
summer internship program for next year: 15 software engineering interns and
5 data science interns, sourced from a mix of 6 target schools (3 top-20 CS
programs, 3 regional state schools where we've had good luck with retention
in the past). Program needs to run June-August, with return offers going out
by early September so we can compete with the big banks and Big Tech firms
who usually decide faster than we do. We also want a real plan for reaching
first-generation and HBCU students this cycle, not just a token info
session — we had zero interns from those pipelines last year. Can you put
together a cycle plan with school-by-school headcount targets, the key
calendar milestones we need to hit, and how we structure the return-offer
decision process so we're not losing candidates to faster-moving competitors?
