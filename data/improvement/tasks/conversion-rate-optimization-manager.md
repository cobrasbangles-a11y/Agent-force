# Task for: conversion-rate-optimization-manager

I run CRO for a subscription meal-kit brand. The checkout gets about 48,000
sessions a week with a 3.1% conversion rate. We ran a test on a redesigned
single-page checkout: after nine days the variant shows 3.5% versus 3.1%,
the tool says "96% chance to beat control," and the VP wants it shipped
today. But the variant also moved the plan selector so the six-meal plan is
preselected instead of the four-meal plan, and our analyst says the traffic
split came out 52/48 when it was set to 50/50. Mobile is 70% of sessions.
Separately, growth wants my next test to be a checkout where the "skip the
first box" option is removed and the cancellation link moves from the
account page into a help-center article, and they want to test showing a
countdown timer that resets on every page load. We have eight weeks before
our holiday code freeze. Should we ship the checkout, what's wrong with the
test, and what should the next eight weeks of testing be?
